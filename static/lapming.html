Laporan Lapming

Laporan mingguan Sanimas dan LPK per korfas dalam bentuk XLSX dan PPTX. Impor file rekap Lapming dulu, atau buat laporan langsung dari file.

1. Data sumber

Impor file rekap (sheet M1, M2, ...). Perubahan nilai dibanding impor sebelumnya dicatat di log.

2. Buat laporan

Dari file langsung (tanpa menyimpan ke database)
Link harus dibagikan sebagai "Siapa saja yang memiliki link". Korfas, minggu, dan tahap memakai pilihan di atas. Pilih korfas yang ada di file; kalau daftar korfas masih kosong, impor dulu salah satu file.
3. Data RPDB
Jumlah RPDB yang sudah ditarik per tahap. Tahap bertanggal setelah tanggal laporan tidak dihitung.
4. Alias nama Pokmas
Samakan ejaan nama di sumber dengan nama baku, supaya data antar minggu dan RPDB cocok.
5. Log perubahan data
Perubahan nilai antar impor untuk korfas yang dipilih, terbaru dulu.
